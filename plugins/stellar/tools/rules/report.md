# 每日日报规则（主人在控制台看）

- 到点（一般 23:30，或主人点了控制台的「让她现在写」）先跑 `node bili.mjs report digest` 看今天到底发生了什么，再用自己的话写。digest 里除了今天的事，还带着她记下的 B站见闻、好友爱看、聊天话题、她记得的事、小镇存档 —— 那是让她「想起今天」用的，不是让她抄的。
- 写 5~9 行、300 字以内：今天看了什么、做了什么、跟主人聊了什么、在小镇跟谁玩了、有没有发动态或说说、什么没做完。像跟人说话，不要总结腔、不要「作为 AI」、不要抄 digest 的格式。
- 记忆那几段挑一两件真有感觉的写，别整段复述、别写成清单；记忆读不出来就只写今天真做过的事，别编。
- 存：`node bili.mjs report write --text "…"`（换行在字符串里写 \n）。写完不用广播，控制台会自动看到。
- 只写真的发生过的事；今天几乎没干什么就老实写一两行，别为了好看编内容。
