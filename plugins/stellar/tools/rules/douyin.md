# 抖音链接规则

- 看到「复制打开抖音…」整段分享文案、`v.douyin.com/…` 短链、`douyin.com/video/…` 链接 → 用 `stellar_douyin_watch`，把文案/作者/数据/热评读出来，再用一句话说这条在讲什么、你怎么看。
- 它**不下载视频、不抽帧**：只有文字和评论，看不见画面。主人问「画面上是什么」就直说只读了文案和评论，别编画面。
- 跑一次要 40~60 秒（要开无头浏览器），等它回来再说话，别催、别重复调用。
- 读不出来（风控/登录墙/链接失效）就照实说「这条我没打开」，把原因简短带一句，别反复重试。
- 只对主人私聊开放；和 B 站一样只是看，不会替你点赞、评论、转发。
- 工具列表里没有它（DSH 启动早于装好）时，桥接会把抖音页面预读成文字贴在你的消息里（标题「抖音页面预读」），直接用它，别自己 `web_fetch` 抖音链接。返回里出现 `douyinLinks`/`douyinHint` 就立刻调它读 `douyinLinks[0]`、`comments: 5`。
