# Stellar 控制台（随仓库发布）

这是完整面板：QQ 聊天、通讯录、记忆库、B站/空间动态、运行日志、设置、隧道都在。
**数据全是从你的 `~/.dsh/stellar` 和仓库里读的**——第一次打开时它们是空的，所以看到的是空卡片，不是坏了。

## 怎么开

双击仓库根目录的 `启动控制台.bat`，**把窗口里那句「本机入口（免输入口令）」的地址整条复制到浏览器**（它带着一次性口令，打开一次之后这台电脑 30 天都不用再输），或者：

```bat
node stellar-manager\server.mjs
```

默认 `http://127.0.0.1:3300`。换端口：`set STELLAR_PANEL_PORT=3301`。

第一次直接打开 `http://127.0.0.1:3300/` 会看到一张口令页 —— 这是**故意**的：控制台在本机也不再免口令（2026-11-16 起），否则同一台电脑上别的账户打 `/api/status` 就能读到口令再从公网隧道进来。口令在 `<DSH_HOME>/stellar/panel-token.txt` 里（Windows 上就是 `%USERPROFILE%\.dsh\stellar\panel-token.txt`），输一次这台设备记住 30 天。

## 第一次打开会看到的

| 卡片 | 空的原因 | 怎么有数据 |
| --- | --- | --- |
| 她此刻在做什么 / 运行状态 | 桥接还没起过 | 双击 `首次启动.bat`，桥接连上 SnowLuma 后就有 |
| 通讯录 | 还没人跟它说过话 | 收到第一条私聊/群消息后自动建档 |
| 记忆 | 缓存还没攒够 | 聊几轮，切分后出现话题；生日这类会自动进「重要事实」。记忆页是一个工作区、六个页签（概览/话题/记忆页/零碎/事实/见闻），概览里能看记忆区、整理作业与做梦状态 |
| 夜间电源 | 默认关闭 | 运行页 →「夜间电源」：开启后 23:50 睡眠、06:05 唤醒；本机没开休眠时只能睡眠 |
| B站 / 空间 | 还没刷过 | 调度器按生物钟跑一轮后就有 |
| 花费 | 还没有用量 | 跑起来后按 DeepSeek 价目折算 |

## 它读哪些文件（都不在仓库里）

- `<DSH_HOME>/stellar/`（默认 `%USERPROFILE%\.dsh\stellar`）：`bili.config.json`、`state/`、`characters/`
- 仓库根目录：`config.json`（桥接配置，跑过一次 `首次启动.bat` 才有）
- 面板自己的口令：`<DSH_HOME>/stellar/panel-token.txt`（首次启动自动生成，**不写进仓库目录**）

## 安全边界

- 默认只监听 `127.0.0.1`；要让同一 WiFi 的手机连，设 `STELLAR_PANEL_HOST=0.0.0.0`，口令在那之后才有意义。
- 连远程建议走 `设置 → 手机访问 → Cloudflare 隧道`，隧道进来的请求默认只读。
- 页面本身不接触桥接的 `consoleToken`：由面板后端转发。

## 端口冲突

`EADDRINUSE` 就是 3300 被占了：换 `STELLAR_PANEL_PORT` 再启动。
