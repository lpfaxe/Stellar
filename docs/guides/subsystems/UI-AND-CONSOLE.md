# 两套界面：插件设置页 + 浏览器面板

> 两套界面服务同一件事，但**位置和权限**不同：设置页在 DSH 里改配置，面板在浏览器里看状态。
> 面板是可选的；没有它 QQ/B站/记忆/每日任务照常跑。

## 0 一张对照表

| | 插件设置页 | 浏览器面板 |
| --- | --- | --- |
| 在哪 | DSH 的「设置 → 扩展 → Stellar」 | `http://127.0.0.1:3300/` |
| 进程 | DSH 自己 | 单独的 `stellar-manager`（`启动控制台.bat`） |
| 页签 | **7 个**：概览 / 她 / QQ / B站 / 记忆 / 角色 / 高级 | **6 个**：概览 / 她今天 / 通讯录 / 记忆 / 运行日志 / 设置 |
| 主要用途 | 改参数（会写进配置文件） | 看现在发生了什么、做临时操作 |
| 能不能没有 | 不能（配置的入口） | 能（纯可选） |
| 鉴权 | 跟着 DSH 走 | 回环免口令；局域网/隧道要口令（见 §4） |

## 1 插件设置页（7 个页签）

| 页签 | 你在这里做什么 |
| --- | --- |
| **概览** | 一眼看状态：桥接连不连、DSH 就绪没、B站 登录态、今天花多少 |
| **她** | 三档运行模式（正常 / 摸鱼 / 最低限度，点一下立即生效）、待办事项（到点她主动提醒，可指定提醒谁）、主动找你的时机（`purpose` 引擎的参数） |
| **QQ** | 白名单/黑名单、唤醒条件、首回复节奏、表情包策略、鱼群保护 |
| **B站** | 生物钟、四类动态、评论/弹幕行为、鱼群保护、额度；页面下部折叠着「观看历史」（她刷过什么、给哪条打了几分） |
| **记忆** | 新记忆库只读概览（话题 / 事实 / 见闻区 / 侧写 / 后台作业）；下面才是叙事 / 向量两种旧方式、向量索引与语义搜索、Embedding 包、双向脱敏同步；写操作在浏览器面板「记忆」页或 `stellar_memory_*` 工具 |
| **角色** | 写人格：名字、称呼、说话风格、雷点、回复示例；角色卡文件的选择 |
| **高级** | 三个子页签：**扩展**（扩展包的开关与状态）、**全部参数**（所有可编辑键的原始表单，出问题时改这里）、**诊断**（自检：缺什么、连不上谁、日志摘录） |

设置页的「改完生效」规则写在每个控件下面：多数配置**下一轮生效**，不用重启；
少数（`consolePort`、MCP 工具开关）要重启对应进程。

## 2 浏览器面板（6 个页签 / 31 张卡）

| 页签 | 卡 |
| --- | --- |
| **概览** | 她此刻在做什么（在线/休眠/情绪）· 快速操作（重启/自检/清理多开/重排生物钟）· 运行模式 · 待办审批 · 今天的**花费** |
| **她今天** | 今天的任务清单 · 她自己拍的图（≤30 张，每日清空）· 她的状态 · 她的 B站 动态 · 今天的 B站 视频 · 今天刷的动态（好友爱看）· QQ空间说说 · 她的日报 · 她的事项 |
| **通讯录** | 成员表（备注/关系/类型/补充）· 人物侧写 · 她发出去的话 |
| **记忆** | 记忆库概览 · 话题目录 · 零碎记忆 · 人物侧写 · 重要事实 · 参考库 · B站 记忆 · 好友爱看记忆 |
| **运行** | 停/唤醒/传话 · 生物钟 · 日志 · 运行数据（调度/记忆/词汇表/表情包） |
| **设置** | 每天做什么（开关 + 目标数）· 谁能跟她说话（白/黑名单）· 她的能力（15 个开关）· 参考库开关 · 远程访问 |

### 五种常见「空」的原因

| 卡片 | 空的时候真的意味着 |
| --- | --- |
| 她此刻在做什么 | 还没开始跑（没配 ownerQQ / 没连上 SnowLuma） |
| 今天的花费 | 桥接不通（右上角会写 HTTP 401/ECONNREFUSED）或今天真没花 |
| 话题目录 / 零碎 | 记忆库还没有切出内容（她还没回过话），不是坏了 |
| B站 视频 / 封面 | 今天还没刷；封面池每天清空，记录留三天 |
| 通讯录 | 名单还没导入（「从 QQ 同步好友/群」） |

## 3 面板怎么连上桥接

面板读的都是桥接的**只读**接口，路径与令牌处理在一块：

```
浏览器 ──► panel:3300 ──(带 x-console-token)──► bridge:3100 ──► SnowLuma / DSH
```

- 面板自己持有 `consoleToken`，**不发给浏览器**。页面上永远看不到令牌；
- 令牌从哪来：`config.json` 的 `consoleToken`，没有就读 `<仓库>/state/console-token`；
- 读不到时面板照常起来，但顶部会显示「桥接不通 —— 先用 首次启动.bat 起一次桥接」。

## 4 谁能打开面板

| 来源 | 看到什么 | 能不能改 |
| --- | --- | --- |
| 本机（127.0.0.1） | 全部 | 能改 |
| 局域网 / 隧道（要口令） | 全部 | 默认**只读**；白名单里加了来源才能写 |

面板默认只监听 `127.0.0.1`。想让手机连，两条路：
Cloudflare 隧道（`配置.bat` → 远程访问）或 Tailscale（见 [../operations/REMOTE-ACCESS-TAILSCALE.md](../operations/REMOTE-ACCESS-TAILSCALE.md)）。

口令是**页面第一次打开时**要输的那个 8 位数字，存在 `stellar-manager/panel-token.txt`；
这台电脑上从回环打开不需要输。忘了就删掉那个文件，下次启动会生成新的。

## 5 刻意不放进面板的东西

- **改消息链路的中间状态**（未读队列、正在生成的回复）—— 那会让「她到底说了什么」变得不可解释；
- **编辑 MCP 工具的输入输出** —— 面板只观察，不代她说话；
- **直接改 `memory.db` 的原始表** —— 只能通过「忘记 / 标为重要 / 编辑事实」这些有语义的操作；
- **重启 DSH** —— 那会打断正在进行的对话。

## 6 面板本身的安全边界

- 只监听回环；对外的路径必须经口令 + 会话 Cookie；
- 写操作要求 `x-panel-request` 头（防跨站），并落 `audit.jsonl`；
- 页面里的「查看令牌」只在本机可见；局域网来源一律打码；
- 详细基线见 [../operations/SECURITY_BASELINE.md](../operations/SECURITY_BASELINE.md)。
