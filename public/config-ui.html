Stellar 配置编辑器

只改你选中的那个 config.json · 表单没覆盖的键会原样保留

一、配置文件

路径由你指定。这个页面不会去扫描磁盘找 config.json。

二、接哪个 DSH

桥接要把 QQ 消息投给一个正在运行的 DSH，这里填它的地址与要用的模型。

dsh.baseUrl
本机一般就是 http://127.0.0.1:3080；端口会随 DSH 重启变，可用「首次启动.bat」或 npm run bootstrap 同步。
dsh.provider
dsh.model
dsh.followDefaultModel
dsh.authToken
留空表示不带鉴权头。填了就会以 Bearer 形式发出去。
dsh.allowRemote

三、是谁在用

白名单为空 = 谁都不理。这是最容易漏的一步。

ownerQQ
只有这个号能改设置、能看控制台之外的敏感信息。
admin
管理员能触发审批类操作，但改不了主人专属的设置。
allow.private
一行一个数字。留空 = 不回应任何私聊。
allow.groups
不在这里的群，一条消息都不会处理。
deny.users
拉黑优先于白名单。
allowAllWhenEmpty
ackMessage
模型慢的时候用户不会以为掉线了。

四、SnowLuma 网关

SnowLuma 是第三方程序，本仓库不代装。它跑起来之后，桥接靠这两个地址连它。

snowluma.httpUrl
snowluma.wsUrl
snowluma.accessToken
这个值属于密码级，别贴进聊天记录或截图。
snowluma.followDiscoveredEndpoint
snowluma.launcherPath
想在这里点按钮拉起 SnowLuma 才需要填。
snowluma.allowLaunch
snowluma.homeDir

五、桥接本体

consolePort
默认 3100。填 0 让系统自动挑一个。
consoleToken
留空最省事：桥接会生成一个写进 state/console-token。自己填要 16~128 位字母数字。
agentPreset
workspaceTitle
在 DSH 会话列表里显示的名字。
sessionCwd
sendDelayMs
0~600000。太小会像机器刷屏。
questionTimeoutMs
role.maxInjectChars
字。太大吃上下文，太小人格会变淡。

六、功能开关

不确定就先保持默认；关掉不会删数据。

biliBridge.enabled
socialV2.enabled
purpose.enabled
fishGuard.enabled
security.interceptNotify
webSearch.provider
webSearch.apiKey
留空时会去读 webSearch.apiKeyEnv 指的环境变量，不落盘更安全。
